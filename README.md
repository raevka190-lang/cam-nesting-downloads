# CAM NESTING — загрузки

[Скачать загрузчик установщика Windows](https://github.com/raevka190-lang/cam-nesting-downloads/raw/refs/heads/main/updates/protected-client/CAM_Nesting_Protected_Download.zip)

1. Распакуйте архив на Windows 10/11 x64.
2. Запустите `Download_Protected_Setup.cmd` и дождитесь **Ready**.
3. Запустите появившийся рядом `CAM_Nesting_Protected_Setup.exe`.
4. В программе: **Лицензия… → Активировать / проверить**.

Загрузчик проверяет SHA-256 частей и готового установщика. Python устанавливать не требуется.

В этом репозитории размещаются готовые клиентские сборки и файлы их загрузки. Сервер активации: https://license.cam-nesting.ru.
