[Скачать загрузчик тестового установщика](https://github.com/raevka190-lang/cam-nesting-downloads/raw/refs/heads/main/tests/trial3/CAM_Nesting_Trial3_Test_Download.zip).

CAM NESTING — ОБНОВЛЁННАЯ ТЕСТОВАЯ СБОРКА НА 3 ДНЯ

1. Распакуйте этот небольшой ZIP и запустите Download_Trial3_Setup.cmd.
2. Дождитесь Ready. Рядом появится CAM_Nesting_Trial3_Test_Setup.exe.
3. Запустите EXE и установите программу. Python не требуется.
4. Откройте ярлык «CAM NESTING · ТЕСТ 3 ДНЯ», подключите интернет и нажмите «Лицензия… → Активировать / проверить».

Для проверки полного срока используйте компьютер, который ещё не активировался на сервере CAM. Пробный период — 72 часа от первой активации компьютера. Повторная установка этой же тестовой сборки не выдаёт новые 3 дня. После окончания срока раскрой и вывод УП требуют активации; проекты можно открыть и сохранить.
Включены актуальные привязки, значки, измерение в раскрое, полилиния из прямых и дуг, сплайн, исправления Num Lock/Орто, кромки на бирках.

Обычная 14-дневная версия и рабочий сервер не изменены. Тест устанавливается отдельно в %LOCALAPPDATA%\Programs\CAM_Nesting_Trial3_Test. Активация компьютера общая: переход с теста на обычную версию не создаёт новую дату первой активации, будет оставшееся время из 14 дней. Платные лицензии не ограничиваются тремя днями.

Загрузчик скачивает части только из публичного репозитория cam-nesting-downloads на GitHub, проверяет SHA256 каждой части и готового EXE. Он не запускает EXE автоматически и не меняет настройки безопасности Windows. Закрытого ключа сервера, исходников программы и пользовательских проектов в установщике нет.
